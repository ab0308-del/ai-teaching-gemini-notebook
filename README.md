# AI教學力～Gemini Notebook從備課到評量

22 頁網頁簡報｜許凱琳老師｜暖色教育風

## 播放

1. 解壓縮整個資料夾，保留 teacher.png 與 images 資料夾。
2. 用 Chrome 或 Edge 開啟 index.html。
3. 左右方向鍵、PageUp／PageDown 或下方按鈕換頁。
4. 右上角可開啟目錄、所有連結與全螢幕。
5. 第4頁附可勾選的課前檢核表；提示詞附複製按鈕。
6. 講師完整介紹可由第2頁的按鈕查看。

文字、樣式與互動程式都在 index.html；插圖與照片使用相對路徑。
Google Fonts 與雲端連結需要網路；離線時會使用電腦上的替代字型。
本機檔案若不允許自動複製，可手動選取提示詞複製。

## 附件
